DAILY REPORT — CHROME EXTENSION (Manifest V3, v1.1)

ВСТАНОВЛЕННЯ
1. Розпакуйте архів у постійну папку.
2. В Chrome відкрийте chrome://extensions/ та увімкніть «Режим розробника».
3. Натисніть «Завантажити розпаковане» та вкажіть папку Daily_Report_Chrome_Extension.
4. Закріпіть іконку Daily Report на панелі браузера.

ОНОВЛЕННЯ ПОПЕРЕДНЬОЇ ВЕРСІЇ
- Не видаляйте розширення: це може стерти його локальні дані.
- Розпакуйте файли поверх попередньої папки розширення та натисніть «Оновити» у chrome://extensions/.
- Перед оновленням рекомендовано зробити JSON backup через «Файл» у повному звіті.

ШВИДКЕ ВІКНО
- Аркуш підбирається автоматично за сьогоднішньою датою: спочатку поточний аркуш із повного звіту, а якщо він не підходить — останній із сьогоднішньою датою.
- +1 / −1 для дзвінків; статистика тижня з урахуванням OFF-днів.
- Кріти та складні люди: перемкніть категорію, за потреби виберіть бренд, вкажіть посилання/ID та/або опис, натисніть «Додати запис». Показуються останні три записи категорії; їх можна видалити.
- «Розгорнути» збільшує це саме popup до 790×580 і завантажує весь Daily Report всередині (без нового вікна браузера).
- «Згорнути» повертає швидкий режим; додатково можна відкрити повний звіт у вкладці.
- Стандартне popup Chrome має ліміт приблизно 800×600 і закривається, якщо натиснути поза ним.

ДАНІ ТА ПЕРЕНЕСЕННЯ
- У старому HTML: «Файл → Резервна копія (json)».
- У розгорнутому режимі: «Файл → Відновити з копії», виберіть JSON.
- Ті самі записи спільні між компактним та повним режимами; вони зберігаються в chrome.storage.local.
- JSON та Excel резервування й імпорт залишилися у повній панелі.
- Не видаляйте розширення без резервної копії: локальні дані можуть бути втрачені.
- Інтернет для роботи не потрібен; розширення не запитує доступу до робочих сайтів.
